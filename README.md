# HealthLens

JavaFX health dashboard assignment covering:
- Java/OOP
- Git/GitHub
- JavaFX layouts and controls
- Responsive property binding
- Multithreading and ExecutorService thread pool
- SQLite + CRUD + table relationship
- HTTP request + JSON parsing

## Run
Open the project in IntelliJ IDEA as a Maven project, then run:

mvn clean javafx:run

Or use IntelliJ Maven -> Plugins -> javafx -> javafx:run.

The SQLite database file `healthlens.db` is created automatically on first run.

## Important
The weather endpoint uses Open-Meteo and does not require an API key.
